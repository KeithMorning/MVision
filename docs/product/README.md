## 产品愿景

连接用户自己的存储，让 AI 自动把零散资料整理成漂亮、可阅读、可搜索、可持续演进的个人 Wiki。

## 核心价值

1. **自有存储**: 数据保存在用户选择的位置，不被应用锁定
2. **漂亮阅读**: 提供接近内容消费产品的体验
3. **AI 编译**: LLM 将新增资料增量整理到持久化 Wiki
4. **来源可追溯**: AI 结论必须能定位到原始来源
5. **多端连续**: 移动端阅读，桌面端生产

## 目标用户

- 软件工程师与技术负责人
- 研究人员、产品经理、设计师
- 长期使用 Markdown、网盘或 NAS 的知识工作者
- 希望用 AI 整理资料但不愿迁入封闭 SaaS 的用户
